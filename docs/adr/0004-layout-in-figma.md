# ADR 0004: Layout und Typografie ausschließlich in Figma

- Status: angenommen
- Datum: 2026-08-04

## Entscheidung

Generative Werkzeuge erstellen nur Illustrationen. Sämtliche spielrelevanten und seriellen Elemente werden als Figma-Komponenten gebaut.

## Folgen

- konsistente Typografie und Kartengeometrie
- Änderungen an Regeln und Texten bleiben möglich
- Illustrationsbriefings müssen crop-safe und frei von lesbarer Schrift sein
